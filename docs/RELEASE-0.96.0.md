# PUDL 0.96.0 release record

Paul requested publication of the new skins and themes on 1 November 2026 after approving their preview appearance. This release includes Matte, Ink, Alloy and Glass, revised Bevel, Gel and Glaze focus treatment, the Glass title-bar correction, and the three companion colour themes. Paul subsequently authorized combining the static execution-state candidate into 0.96.0. The combined release requires specification 0.52.3 and renewed integration review before publication.

## Glass title preview follow-up

Paul reenabled workstation motion and transparency and requested a translucent title-bar preview. The experiment uses ordinary `prefers-reduced-transparency: no-preference` and filter-support queries, with no preference override. It tints and blurs the continuous header while retaining opaque controls and transparent title text backgrounds. Reduced transparency and unsupported filtering retain the current opaque header. The sample-only experiment is linked by `samples/skins.html` through `samples/glass-title-preview.css`. Light and dark checks passed in Chromium, Firefox and WebKit with normal system preference handling; Chromium reduced-transparency checks restore the opaque header without changing window bounds. Captures and measured paint are retained in `tests/output/glass-title-translucent-preview`. The attempt to open the preview through the browser UI tool failed because its host was unavailable, so the local preview URL is supplied directly. Paul reported that the effect remained visible only in the border. The first preview retained the window's 72% frame fill behind its translucent header, masking most of the background. The corrected preview removes that full-window fill and paints the frame band with an inset shadow, leaving a 72% tinted header over the actual backdrop. Both active and inactive headers now respond by 71 RGB levels when the background changes from black to white in a text-free sample region. The earlier computed-style checks established blur and alpha but did not establish perceptible background transmission. Six engine/form checks and the Chromium reduced-transparency fallback check pass again. The sample stylesheet URL is versioned to refresh the earlier preview. The experiment is not an admitted skin change; publication waits for visual evaluation and any resulting re-review.
