## Plan before runtime edits

Reproduce the rendered row name and missing shortcut metadata using tagged bytes. Mark only .menu-row-key decorative text aria-hidden and add aria-keyshortcuts to the command row. Preserve meaningful detail, disabled reason, state and visible hint. Derive modifier metadata from normal()/spelling(), without altering execution. Mod/Ctrl/Cmd/Meta normalize to Mod, and spelling accepts Control, Meta or both simultaneously, so expose those alternatives explicitly. Standard ARIA modifier tokens are not display abbreviations. The existing dispatcher ignores the modifier spelling Control; record that limitation instead of silently changing activation. Literal space maps to ARIA Space. Unsupported/nonrepresentable key spellings retain their visible hint but receive no invented metadata. Use a shared conversion only within rows; the existing ordinary-control conversion is a separate known limitation, outside this patch.

Use exact accessible-name assertions for direct and actually folded command rows, dynamic shortcut addition/change/removal, checked/disabled reasons, and enabled/disabled click and shortcut execution. Source/min three-engine regressions and unchanged existing command/toolbar tests must pass before independent review. No commits or packaging occur.

[WAI-ARIA keyshortcuts grammar](https://www.w3.org/TR/wai-aria/#aria-keyshortcuts) defines a space-separated list of alternatives, plus-separated keys, standard modifier names and Space/Plus spellings. Metadata describes implementation; it does not install key handling. No platform display heuristic can prove the dispatcher's behavior.

## Confirmed red and implemented boundary

Expanded harness iterations retain their failures separately: initial assertions read menu rows before their opening update completed and later expected the menu to remain open after a disabled interaction. The corrected test waits for the actual opened row and reopens a closed command menu when testing later updates. No runtime assertion or timeout was weakened.

The implementation adds rowShortcuts() beside the display formatter. It uses the existing normal() parser and exposes Control, Meta and simultaneous Control+Meta alternatives for Mod-family chords, retaining Alt/Shift. Space is emitted only for the literal-space key the dispatcher accepts; named Space and Plus aliases are not implemented by the dispatcher and are not advertised. Common standard named keys and printable single characters are representable; other spellings retain their visible hint without metadata. Execution is unchanged. In particular, Control as a modifier is ignored by the current dispatcher, so Control+F9 dispatches F9 and row metadata reflects F9. This surprising existing behavior is a separate parser issue, not repaired here. Ordinary controls' existing metadata conversion also remains outside this row-only correction. bind:false remains a host-owned binding declaration, whose actual execution is not certified by this component test.

The shortcut span alone gains aria-hidden=true. Reasons, details, badges, checkbox/radio state and visible hints are preserved. Dynamic open-menu reconciliation uses its existing attribute/content synchronization, removing stale metadata when a shortcut is removed. No tooltip, dispatcher, CSS or toolbar runtime is modified.
