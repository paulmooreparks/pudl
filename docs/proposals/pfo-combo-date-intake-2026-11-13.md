## Lead disposition after assessment

The proposed new form-wide reporting helper is not approved. The lead's HTML Standard review identifies a smaller route for assessment: cancel the hidden source's reporting, keep its visible proxy's invalid event uncancelled, and let native interactive validation report that rendered proxy. Static validation does not perform interactive reporting, so the component need not infer the caller's intent. The standard permits browser focus rather than requiring a particular focus target; the contract must preserve that distinction. Persistent component feedback may accompany both routes without component-driven focus. The specification collects invalid controls before firing their events, so validity must already be synchronized before a form validation call; late invalid-event mirroring alone cannot establish proxy participation. The engineer must assess this route and its documented refresh boundary before runtime edits. Reference: https://html.spec.whatwg.org/multipage/form-control-infrastructure.html#constraint-validation.
