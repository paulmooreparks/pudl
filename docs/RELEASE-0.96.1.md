## Release decision and follow-up

The documented residual intermittent CI risk is accepted for 0.96.1, following the independent recommendation in tests/output/release-0961-intermittent-ci-risk-disposition.md. The completed checks show no candidate-specific regression; the two initiating Linux failures remain unexplained. Main CI passed all five jobs. Tag attempt 1 remains 113/115 WebKit, with its separate unchanged-input rerun at 115/115. The clean 690-execution serial matrices and paired-tag diagnostic support release without claiming cause closure. The diagnostic server recorded no failed requests, but browser evidence includes one cancelled old-tag sample request 419ms after its successful sidebar measurement; no candidate failure is inferred from it.

Follow-up work covers failure-safe underlay cleanup, observable bounded wheel completion, and ordinary splitter resize/geometry/ARIA synchronization. Preserve the current endpoint, containment and metadata assertions. On recurrence, capture actual values and event/target progression before retrying. The ResizeObserver in the existing runtime serves persistent layouts, not the ordinary sidebar. A persistent metadata mismatch or candidate-only reproduction requires product investigation. These follow-ups do not change the immutable 0.96.1 tag.
