PUDLHost launcher studies

One catalog, three kinds of host

These working demos explore finding applications, browsing content and opening desktop tools through the host title. They use PUDL's menu bar, applet, Start, splitter and window controls.

The shared menu bar's direct launcher integration is on main and awaits a versioned release. The host adapter adds opener placement, persistent presentation and remembered size as sample code for review.

Other launcher positions

What you can try

The host title toggles its catalog open and closed. Type to search, select a category and use the divider with a pointer or keyboard. Press the pin glyph to keep the catalog open as a pane, resize it, collapse it, and reveal it again. Press the pin again to return to a popup. The Size disclosure provides keyboard-accessible popup dimensions; the popup also has a native resize grip.

Open several destinations and use their real PUDL window controls and taskbar. Copy the address to share the selected catalog state and open windows. Back and Forward restore navigation. Preferences and working drafts remain in this browser. Reset demo preferences restores the initial presentation and geometry without clearing working drafts or checklist entries.

For implementers

The catalogs and tools are illustrative. They are not connected to production accounts, article services, app registrations or native desktop bridges. Single-application mode uses a query parameter to demonstrate host policy; production hosts supply their own subdomain URLs and unsaved-work rules.

PUDL owns the menu bars and their hamburger controls, active application menus, catalog filtering, category interaction, keyboard navigation, splitters and windows. The shared sample adapter owns URL integration, local preferences, opening policy, popup placement and the presentation switch. The same catalog node is retained while changing presentation.
