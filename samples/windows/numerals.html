Tabular numerals and the hyphen

30 August 2026

Tabular numerals give every digit the same width, so a column of amounts or timestamps lines up without any help. PUDL used to switch them on for the whole page.

Inter, the face PUDL now ships, widens the hyphen along with the digits when the feature is on, since a hyphen in a table of dates wants to line up too. In running prose it spaced out every hyphenated word, so PUDL now applies tabular numerals where numbers are data: tables, fields, badges, lists and anything marked as a time or a value.
