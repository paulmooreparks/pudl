Keeping state in the URL

14 September 2026

Every window on this page lives in the address bar. Open two articles, restore one to a floating window and drag it somewhere, then reload. Everything comes back where you left it, because there was never anywhere else for it to be.

The grammar is small. The open parameter lists the open windows, top names the one in front, min lists the minimised ones, and one p. parameter per window gives its placement as fractions of the space the windows float in.

Two listings go with this article. Listing 1 is an address with three windows in it, and Listing 2 is the function that reads a placement back. Open both, and the list shows each under this article.
