Combo boxes

A combo box takes any value, and its list only suggests; a searchable select keeps to its options. Try typing, ↓ ↑, Alt+↓, Enter, Esc twice and Tab, and press the button at a field's end.

A currency sign

The field holds the sign. Type the code, such as PHP or HKD, or the currency's name, and the sign goes in; a sign that is not listed may be typed too.

Three Nordic currencies share kr, so each is found by its own code.

A searchable select

The value must be one of the options; typing only finds it. Leave the field with something that is not an option and the choice comes back.

Options from the server

With data-combo-src the options are asked for after a pause in typing. This page has no server, so it asks a file and the script filters what comes back. Type "plan" or "notes".

Completing as you type

Off unless a field asks for it with data-combo-complete. Type "Si" or "Ho".

In a toolbar and a dialog

In a toolbar the field keeps its own keys, and the arrows pass over its button. In a dialog the list opens above the backdrop.

What the application hears

Each field's input and change, as from any text field, or from the select.
