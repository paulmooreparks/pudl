PUDL, the Pleasantly Usable Design Language

PUDL pairs a parchment palette and a heraldic-navy default accent with a control grammar taken from GTK: raised buttons, sunken inputs, segmented controls, a master-detail layout, filter chips, key/value tables, switches and server-rendered dialogs. Elevation signals interactivity, so raised means pressable, sunken means input and flat means display. Colour is never the only signal, and every meaningful state carries a glyph.

1. Tokens

Two themes: parchment-light and leather-dark. Topbar stays as warm leather chrome in BOTH themes (not the GTK light bar). Accent recolour propagates across links, primaries, focus rings, segmented active state, filter chips, badges.

8. Dialogs

Server-rendered, shown by JS, never a native confirm(). Backdrop dims gently; the panel is an elevated surface (one step brighter than the page, large drop shadow). Two actions: cancel left, commit right (danger commit carries ⚠).

9. Master–detail layout (the new primary layout)

Resizable sidebar (260 px default) + detail pane. Toolbar pinned to the top of the layout. Filter chips render between the toolbar and the body. Active sidebar row gets the 3 px accent edge facing the detail. The same primitive serves any list-and-detail view.

10. Floating windows

Records can open as draggable windows above a list. The window border is a composite resize affordance (old-Windows style): a 1 px outer line, a fill band in the card-toolbar colour, and a 1 px inner line, 4 px total. The whole band is the drag zone; there is no separate corner glyph. Both lines stay 1 px and use the standard --border colour; only the fill band changes width (token --rb-band). The active window tints its outer line with --accent and takes the larger shadow. Maximized and snapped windows collapse the band to a single edge.

11. Invariants

  • Elevationraised = pressable, sunken = input, flat = display.
  • Buttonsone look. Every button is raised. Max one .btn-primary per visible context.
  • Colournever alone. Every meaningful state carries a glyph.
  • Linksunderlined. Brand wordmark is the only exception.
  • Numeralstabular everywhere: identifiers, counts, money, timestamps.
  • Tabsactive notebook tab merges with content (baseline punch-through).
  • No breadcrumbs.Every full-screen page anchors to a tab bar somewhere in the hierarchy (topbar mode tabs or the section bar below them). If a page wants to live below the deepest tab strip, it's either a dialog or a one-off that merits a redesign of the page structure. When in doubt, expand the tab structure rather than growing a breadcrumb trail.
  • Topbarleather-dark in both themes (PUDL's signature chrome).
  • Dialogsserver-rendered. No native confirm(). Panel one step brighter than the page; backdrop dims gently (40%); large drop shadow does the elevation work, not the backdrop opacity.
  • TimeISO UTC in data; local time display-only.
  • Recolourchanging --accent propagates across links, primaries, focus rings, segmented active, chips, badges.
